# GitHub Global - 快速启动说明

本文档用于帮助您在本地快速启动项目，并按当前实现完成登录与仓库同步。

## 前置要求

- Node.js 20+
- MySQL 8+
- 一个 GitHub OAuth App
- 一个 GitHub App
- OpenRouter API Key（用于翻译）

## 安装步骤

### 1. 安装依赖

```bash
npm install
```

### 2. 配置环境变量

```bash
copy .env.example .env.local
```

然后额外创建一个最小化的 `.env`，只给 Prisma CLI 使用：

```bash
Set-Content .env 'DATABASE_URL="mysql://root:password@localhost:3306/github_global"'
```

然后编辑 `.env.local`：

```env
DATABASE_URL="mysql://root:password@localhost:3306/github_global"
ENCRYPTION_KEY="your-64-char-hex-key"

GITHUB_CLIENT_ID="your_github_oauth_client_id"
GITHUB_CLIENT_SECRET="your_github_oauth_client_secret"
GITHUB_OAUTH_CALLBACK_URL="http://localhost:3000/api/auth/callback"

GITHUB_APP_ID="your_github_app_id"
GITHUB_APP_SLUG="your_github_app_slug"
GITHUB_APP_PRIVATE_KEY="-----BEGIN RSA PRIVATE KEY-----\n...\n-----END RSA PRIVATE KEY-----"
GITHUB_APP_WEBHOOK_SECRET="your_webhook_secret"

APP_BASE_URL="http://localhost:3000"
GITHUB_APP_WEBHOOK_URL="http://localhost:3000/api/webhooks/github"
QUEUE_CONCURRENCY=5
```

> 约定：
> `.env.local` 保存完整应用配置；
> `.env` 只保留 `DATABASE_URL`，避免 Prisma CLI 和应用运行时各自读到不同的整套配置。

> 本地开发请统一使用 `localhost`，不要混用 `127.0.0.1`。

### 3. 初始化数据库

```bash
npx prisma db push
npx prisma generate
```

### 4. 启动开发服务器

```bash
npm run dev
```

访问：

```text
http://localhost:3000
```

## 当前登录流程

1. 访问首页 `/`
2. 点击“使用 GitHub 登录”
3. 系统直接跳转到 `/api/auth/signin`
4. 在 GitHub 完成授权
5. OAuth 回调成功后进入 `/dashboard`

> 当前正常登录流程不再经过 `/login` 页面。

## 首次使用建议流程

1. 从首页完成 GitHub OAuth 登录
2. 进入 `/repositories`
3. 如果未安装 GitHub App，点击“管理仓库权限”或安装入口
4. 完成 GitHub App 安装后返回仓库页
5. 点击刷新或同步安装状态
6. 进入仓库配置页设置目标语言、文件规则和翻译引擎
7. 触发翻译并在 `/tasks` 查看结果

## 常见问题

### 1. GitHub OAuth 回调失败

检查：
- GitHub OAuth App 的 Authorization callback URL 是否为
  `http://localhost:3000/api/auth/callback`
- 当前访问域名是否为 `localhost`
- 不要使用 `127.0.0.1:3000`

### 2. 登录后又被送回 GitHub 登录

先检查：
- 当前服务是否已经重启到最新代码
- 浏览器是否确实使用 `http://localhost:3000`
- Cookie 是否被浏览器拦截

### 3. GitHub App 安装后仓库不显示

检查：
- 安装时是否选择了仓库
- 是否已经回到 `/repositories` 点击刷新
- GitHub App 权限是否包含仓库内容和 Pull Requests

### 4. 端口被占用

```bash
netstat -ano | findstr :3000
taskkill /PID <PID> /F
```
